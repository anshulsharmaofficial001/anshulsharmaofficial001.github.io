# Anshul Sharma — Cybersecurity Portfolio

Futuristic dark-themed portfolio website for Anshul Sharma, Penetration Tester & Cyber Security Researcher.

## 🚀 How to Deploy on GitHub Pages (Free Hosting)

### Step 1 — Add your photo
- Rename your photo file to `photo.jpg`
- Place it inside the `portfolio/` folder

### Step 2 — Create GitHub Repository
1. Go to [github.com](https://github.com) and login
2. Click **New Repository**
3. Name it: `anshulsharmaofficial001.github.io`
4. Set it to **Public**
5. Click **Create Repository**

### Step 3 — Upload Files
1. Click **uploading an existing file**
2. Upload ALL files from the `portfolio/` folder:
   - `index.html`
   - `style.css`
   - `script.js`
   - `photo.jpg` (your photo)
3. Click **Commit changes**

### Step 4 — Enable GitHub Pages
1. Go to repository **Settings**
2. Click **Pages** (left sidebar)
3. Under Source, select **Deploy from a branch**
4. Select **main** branch → **/ (root)**
5. Click **Save**

### ✅ Your portfolio will be live at:
**https://anshulsharmaofficial001.github.io**

Add this link to your resume! 🎉
